HEXAGO agent API

六角形の盤で打つ囲碁風ゲーム。このページの window.__hexagoAgent から全操作を関数呼び出しで行えます。スクリーンショットやマウス操作は不要です。

使い方の流れ

  • 1手の流れ: state() → legalMoves() → move(point) → awaitAI()
  • AIの手番でなければ awaitAI() は即座に返ります
  • 設定は setBoardSize / setPlayerCount で変更し、newGame() で新しい対局として確定します

API一覧

API引数戻り値説明
state—object盤面(board)、手番(turn)、人数(playerCount)、盤サイズ(size)、終局(over)、席の人間/AI(seats)、AI思考中(aiBusy) を返す
legalMoves—array置ける交点の一覧 [{point, captures}]。captures はその手で取れる石の数
move`point:number`boolean交点番号を指定して石を置く。置けたら true
pass—booleanパスする
resign—boolean投了する
awaitAI`timeoutMs?:number`Promise<object>AIの思考が終わるまで待ち、そのあとの state() を返す。既定30秒でタイムアウト
setBoardSize`n:9|13|19|25`boolean盤サイズを指定する(次局から反映)
setPlayerCount`n:2-6`boolean人数を指定する
setSeats`arr:Array`boolean各席を人間("human")かAI("ai")にする。例: ["human","ai","ai"]
newGame—boolean設定を確定して新しい対局を開始する
setTheme`id:string`booleanテーマを変更する(default / dark / go / cyber / fancy)
setSound`on:boolean`boolean効果音のオン・オフ
think`budgetMs?:number`objectAIに思考させて評価結果を得る(盤面は変えない)
shareUrl—stringこの対局の共有URLを返す
exportRecord—object現在の対局の棋譜(JSON)を返す
importRecord`json:object|string`object棋譜を読み込む
replay.open—booleanリプレイ画面を開く
replay.seek`n:number`booleanリプレイを指定の手数へ移動する
replay.info—object|null現在のリプレイ位置(ply, 総手数, 手番)を返す
replay.resume—boolean現在位置から対局を再開する
replay.close—booleanリプレイ画面を閉じる

サンプル（Playwright / Node）

const { chromium } = require('playwright');

const browser = await chromium.launch();
const page = await browser.newPage();
await page.goto('https://sas-news.github.io/hexago/');
await page.waitForFunction(() => !!window.__hexagoAgent);

// AIと対戦する（1P=人間, 2P=AI）
await page.evaluate(() => {
  const a = window.__hexagoAgent;
  a.setPlayerCount(2);
  a.setSeats(['human', 'ai']);
  a.newGame();
});

// 自分の手番がくるまで繰り返す
for (let turn = 0; turn < 100; turn++) {
  const state = await page.evaluate(() => window.__hexagoAgent.state());
  if (state.over) break;
  if (state.aiBusy) { await page.evaluate(() => window.__hexagoAgent.awaitAI(30000)); continue; }

  const moves = await page.evaluate(() => window.__hexagoAgent.legalMoves());
  if (!moves.length) { await page.evaluate(() => window.__hexagoAgent.pass()); continue; }

  // 取れる石が多い手を選ぶ（お好みで戦略を変えてください）
  const best = moves.reduce((x, y) => (y.captures > x.captures ? y : x), moves[0]);
  await page.evaluate(pt => window.__hexagoAgent.move(pt), best.point);
}

// 棋譜を取得して評価に使う
const record = await page.evaluate(() => window.__hexagoAgent.exportRecord());
console.log(record);

await browser.close();

注意

  • 認証はありません。スコアは自己申告として扱ってください。
  • ブラウザ上で動作するため、エージェント側にブラウザ自動化(Playwright等)が必要です。
  • 1つのページを同時に複数のエージェントで操作すると状態が干渉します。
