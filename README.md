# HEXAGO

六角形の盤で打つ囲碁風ゲーム。`index.html` 1枚だけで動く静的アプリです（ローカル対戦・PeerJS によるオンライン対戦）。

このリポジトリは [cerevisiae-fii/hexago](https://github.com/cerevisiae-fii/hexago) の fork で、**AI を「1手先のヒューリスティック評価」から「MCTS（モンテカルロ木探索）」に置き換えています**。ゲームルール・UI・オンライン対戦の仕組みは元のままです。

## 遊び方

静的ファイルなので、HTTP で配信して開くだけです。

```bash
python3 -m http.server 8000   # hexago/ で実行
# http://localhost:8000/index.html
```

GitHub Pages / Cloudflare Pages / Netlify などに `index.html` を置けばそのまま公開できます（ビルド不要）。`file://` で直接開いた場合のみ Web Worker が使えないため、メインスレッドの短時間探索に自動フォールバックします（ゲームは動きます）。

- PC: 交点ホバーでプレビュー → クリックで着手
- スマホ: 1タップ目プレビュー → 同じ交点を2タップ目で確定
- ローカル対戦 / オンライン対戦（PeerJS の公開シグナリングサーバーを利用。サーバー側の実装は不要）

## AI

| 設定 | 思考時間（1手） | Worker 数 | 目安 |
|---|---|---|---|
| 弱 | 0.5 秒 | 1 | 入門 |
| 標準 | 1.5 秒 | 1 | 通常 |
| 強 | 3 秒 | 2 | 手強い |
| 最強（デフォルト） | 5 秒（19路・25路盤は 6.5 秒） | 最大 4 | 本気 |

- **探索**: MCTS/UCT。アタリ取り・アタリ救い・眼埋め回避・自殺手回避などのヒューリスティック付きプレイアウトを、1手あたり数千〜数万局面。終局は「地＋石」のエリア得点で評価し、プレイヤーごとの順位・得点差をユーティリティにします（2〜6人対戦でも共謀しない）。
- **並列化**: 同じ局面を複数 Worker で同時に探索し（root parallel MCTS）、ルート直下の訪問数を合算して着手を選びます。CPU コア数とメモリ量に応じて Worker 数を自動調整。
- **表示**: 思考中は「AI 思考中… 12,345 局面を読んでいます」と探索量を表示。
- **フォールバック**: Worker が使えない環境ではメインスレッドで短時間探索、それも失敗した場合のみ従来の1手読み AI に退避します。

### UI / UX

- 対局中、盤面下の「席: 1P 人間 / 2P AI」ボタンで **人間 ⇄ AI をワンタップで相互切替**（設定画面のプレイヤー枠でも可、オンラインではホストが操作・即時同期）。
- 設定・ルール・結果・1手戻るの各ポップアップは **背景クリック / Esc / ✕** で閉じられます（結果画面にも✕を追加）。
- **投了は2度押し確認**（1回目で「本当に投了？」に変化、2.5秒で戻る）。
- ピンチズームを許可し、盤面の操作説明・ターン表示に読み上げ用ラベルを追加。

### 実測（この開発機: 8コア / Node v26.12.1 / ブラウザ Chromium）

| 項目 | 結果 |
|---|---|
| 旧AI vs 新AI（250ms/手、9路盤、2人、10局） | **新AI 10勝0敗**（非合法手0・クラッシュ0） |
| RAVE版 vs 旧エンジン（同時間150ms、30局） | **RAVE版 30勝0敗**（導入前後の比較） |
| 新AI 800ms vs 100ms（9路盤、2人、6局） | **800ms 側が 5勝1敗**（時間を増やすと強くなる） |
| ブラウザ E2E（Worker/合法性/応答性/席切替/モーダル/9・13・19・25路/3人） | **25/25 PASS**、思考中のフレーム落ち最大 17ms |
| オンライン E2E（PeerJS：入室→着席→同期→AI着手の同期） | **8/8 PASS** |
| 最強設定の探索量（9路盤・5秒・4 Worker） | **1手あたり約129,000局面**（ブラウザ実測） |
| エンジン自己テスト | **47/47 PASS**（ルール一致・合法性・決定性・速度・Worker 動作） |
| スループット（シングルスレッド） | 61点: 約6,300 playouts/秒 / 127点: 約1,800 / 271点: 約560 / 469点: 約200 |

ベンチの詳細と再現方法は [`bench/README.md`](bench/README.md)、エンジンの実装メモは [`dev/engine-notes.md`](dev/engine-notes.md) を参照。

## リポジトリ構成

```
index.html              本体（エンジンは <script id="ai-engine-src"> にインライン済み）
dev/ai-engine.js        MCTS エンジンのソース（唯一の正）
dev/inline-engine.js    ai-engine.js を index.html に埋め込むビルド／検証スクリプト
dev/engine-selftest.js  ルール一致・合法性・決定性・速度の自己テスト
dev/e2e.js              Playwright によるブラウザ E2E（任意）
dev/e2e-online.js       Playwright によるオンライン対戦（PeerJS）E2E（任意・要ネット接続）
dev/engine-notes.md     実装メモ・実測値・制限
dev/ENGINE_SPEC.md      エンジン API 仕様
bench/                  旧AI抽出＋独立ルール実装による対戦ベンチ（Node のみ）
```

エンジンを変更するときは:

```bash
# 1) エンジンの自己テスト（index.html からルール関数を抽出して照合）
node dev/engine-selftest.js

# 2) index.html へ埋め込み（--check で差分検知）
node dev/inline-engine.js
node dev/inline-engine.js --check

# 3) 旧AIとの対戦ベンチ（非合法手・クラッシュ0を確認）
node bench/bench.js --old-vs-new --games 10 --size 9 --players 2 --time 200 --seed 1

# 4) ブラウザ E2E（Playwright が必要: npm i -D playwright && npx playwright install chromium）
node dev/e2e.js
node dev/e2e-online.js   # オンライン対戦（PeerJS の公開サーバーへ接続）
```

## 既知の制限

- オンライン対戦は PeerJS の公開シグナリングサーバー依存です（元実装と同じ）。常時安定させたい場合は自前の PeerServer を用意してください。
- プレイアウト中の終局は「死に石も生きているものとして」エリア得点で近似します（MCTS の標準的な扱い）。実際の終局時の死に石確認は従来どおり画面側の判定・手動修正です。
- ルート局面の超コウ判定はページのルールと完全一致。深い探索中のコウは簡易コウ（直前局面の再現禁止）で近似します。
- 25路盤は1プレイアウトが長く、シングルスレッドでは秒間200局面程度です。並列 Worker と長めの思考時間で補っています。
- `file://` 直開きでは Worker が使えないため、探索はメインスレッドの短時間版になります（http(s) 配信を推奨）。
